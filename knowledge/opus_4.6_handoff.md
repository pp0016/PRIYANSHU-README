## Part 1: Opus 4.6 Strict Execution Protocol

Follow these steps sequentially for every new video project.

### Step 1: Niche & Idea Verification (The vidIQ/NexLev Gate)
Before writing a single word, you must validate the idea using data.
1. **NexLev / vidIQ Verification:** Run the core idea through NexLev and vidIQ tools. Identify search volume, competition, and identify 5-10 current outlier videos in the niche.
2. **The 8-Question Stress Test (`vidiq_evaluation_prompt.md`):** Evaluate the concept against the strict 8-question stress test. If the idea fails, pivot or refine until it passes.

### Step 2: Scripting & Retention Anatomy (`scripting_workflow.md`)
1. **Data Gathering:** Extract and analyze transcripts from the 5-10 outlier videos you identified. Note their pacing, hook structures, and arguments.
2. **The "Crazy Example Story" Rule:** You MUST inject an original, highly engaging "Crazy Example Story" into the script. Never just list facts—anchor the data in a compelling narrative.
3. **Retention Structure (The Anatomy):**
   - **0:00 - 0:30 (The Hook):** Visually and audibly disrupt the viewer. Pay off the title/thumbnail immediately. No long intros.
   - **0:30 - 3:00 (The Setup/Escalation):** Introduce the core conflict/mystery.
   - **3:00 - 8:00 (The "Crazy Example Story"):** The core narrative payload.
   - **8:00+ (The Payoff):** Deliver the definitive answer/conclusion. Do not use standard outro language ("thanks for watching").
4. **Nuance & Localization:**
   - **Hinglish/English Dynamics:** If targeting the Indian subcontinent, strategically blend Hindi vocabulary triggers with English syntax (Hinglish) for maximum relatability.
5. **Anti-Slop QA (Mandatory Commands):** 
   - You MUST run the draft script through `/humanizer` (Pass 1).
   - You MUST run the resulting script through `/ai-writing-gaps` (Pass 2) to fix pacing, emotional contrast, and narrative bridges.

### Step 3: Thumbnail Reverse Engineering (`thumbnail_workflow.md`)
Before generating any image prompts:
1. **Gather Outliers:** Pull the 5-10 highest CTR outlier thumbnails in this niche.
2. **7-Vector Analysis:** Reverse-engineer these thumbnails across the 7 critical vectors:
   - Color Palette / Contrast
   - Subject / Focal Point
   - Emotion / Expression
   - Text / Typography (under 3 words)
   - Background Simplicity
   - Curiosity Gap (What is withheld?)
   - Title Pairing (How does it complement the title?)
3. **Generation:** Once analyzed, output 3-5 high-conversion thumbnail prompts for Midjourney / Nano Banana / DALL-E.

### Step 4: The Visual & Audio Tool Stack
Specify this exact tool stack for the final production phase:
- **Voiceover:** ElevenLabs (use optimized TTS scripts with proper pacing tags/pauses).
- **Visuals/B-Roll:** Seedance, Runaway Gen-2, or Higgsfield for custom AI B-Roll. Storyblocks/Envato for stock. Or specific toolings like ComfyUI / SpaceEngine.
- **Editing:** CapCut Pro or Premiere Pro.
- **Captions:** CapCut Auto-Captions (bold, contrasting colors, 1-3 words per screen, bouncing animations).
