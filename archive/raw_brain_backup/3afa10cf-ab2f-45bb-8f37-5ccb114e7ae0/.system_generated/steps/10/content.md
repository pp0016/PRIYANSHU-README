    <h2>Why the tool is free</h2>
    <p>100% client-side processing using WebGPU — your device does all the work, videos never touch our servers. Because we have zero server costs, we can offer unlimited free service with no signup, no watermarks, and no time limits. Complete privacy: no one sees your videos, not even us.</p>
    <p>Other "free" tools either require signup (Canva), add watermarks (Hitpaw), have time limits, or require software installation (Topaz, Waifu2x). Processing happens on your device with zero setup. Also open source — code available on GitHub.</p>

    <h2>Overview</h2>
    <p>Free AI Video Upscaler is an open-source, browser-based video upscaling tool that uses WebGPU technology to process videos entirely in your web browser. This means:</p>
    <ul>
        <li><strong>Zero cost to you:</strong> No server processing fees</li>
        <li><strong>Unlimited use:</strong> Process as many videos as you want</li>
        <li><strong>Privacy:</strong> Your videos never leave your device</li>
        <li><strong>No signup:</strong> Start upscaling immediately</li>

    <h2>The Technology</h2>

    <h3>WebGPU & WebGL Processing</h3>
    <p>We use WebGPU (or WebGL as fallback), web standards that allow GPU-accelerated computing directly in your browser. This enables:</p>
    <ul>
        <li>AI-powered video enhancement</li>
        <li>Client-side processing (your computer does the work)</li>
        <li>No file uploads to external servers</li>
        <li><strong>WebGPU:</strong> Faster processing (2-5x) on Chrome, Edge, and newer Safari versions</li>
        <li><strong>WebGL:</strong> Automatic fallback for Firefox and older Safari, same quality but slower processing</li>
    </ul>

    <h3>How It's Different from Other Free Tools</h3>
    <ul>
        <li><strong>Canva:</strong> Free but requires signup, 1 minute limit, 1080p max</li>
        <li><strong>Hitpaw:</strong> Free version has 10 min limit, adds watermark, requires download/install/GPU setup</li>
        <li><strong>Waifu2x/Video2X:</strong> Free but requires technical setup, command line, GPU drivers</li>
        <li><strong>Topaz/TensorPix:</strong> High quality but paid ($299 or $30/hour)</li>
        <li><strong>Free AI Video Upscaler:</strong> Works instantly in browser, no signup, no watermark, no limits, truly free forever</li>
    </ul>

    <p><strong>The secret:</strong> We use optimized AI models that run efficiently in your browser using WebGPU. Because your device does the work (not our servers), we can afford to let you upscale unlimited hours at zero cost to either of us.</p>

        <li><strong>Safari 16+</strong> - Uses WebGL fallback, Safari 26+ will have WebGPU enabled by default</li>

    <h2>Troubleshooting</h2>

    <h3>"WebGPU/WebGL Not Supported" or "WebCodecs Not Supported"</h3>
    <ul>
        <li>Update your browser to the latest version (Chrome 94+, Edge 94+, Opera 80+, Safari 16+, Firefox 130+)</li>
        <li>Try Chrome or Edge (best compatibility with WebGPU)</li>
        <li>Firefox and Safari will automatically use WebGL fallback if available</li>
        <li>Check if your GPU drivers are up to date</li>
        <li><strong>Main limitation:</strong> WebCodecs API support (not available on older browsers or Firefox Android)</li>
    </ul>

    <h3>Processing Very Slow</h3>
    <ul>
        <li>Close other browser tabs</li>
        <li>Close other applications</li>
        <li>Check GPU usage in browser task manager</li>
