## 6 Universal DNA Patterns (All 4 Channels Share)

1. **Zero-Latency Noun-First Cold Open** — No "in this video" or branding. Topic name drops in the first second.
2. **Tactile Sensory Grounding** — Weird physical details over abstract generalization ("typewriters added a dedicated key for the SS rune").
3. **Deliberate Register Collision** — Modern slang meets historical gravity ("Bro could have really used a prenup").
4. **Sources as Story Actors** — Sources introduced as scenes, not bibliographies ("in an abandoned stone quarry in Pennsylvania").
5. **Sub-5-Second Mic-Drop Outros** — No summaries, no "thanks for watching," no subscribe begging.
6. **Non-Linear Pacing Modulation** — Intensity spikes followed by tonal breathers, never flat.

| # | Check |
|---|---|
| 1 | Wrong Detail — would someone remember this fact tomorrow? |
| 2 | Emotional Whiplash — tonal shift after every intense section? |
| 3 | Source as Story — named sources have scenes, not credentials? |
| 4 | Modern Language Collision — 3-4 deliberate register mismatches? |
| 5 | One-Word Drop — new segments open with standalone topic name? |
| 6 | Narrator Has a Body — narrator reacts as a person each segment? |
| 7 | Causal Transitions — Segment A's ending creates need for Segment B? |
| 8 | Courage in Voice — at least 2 unhedged positions? |
| 9 | Oral Rhythm — every sentence sounds right read aloud? |
| 10 | Pop Culture Anchoring — complex concepts explained via comparison? |
| 11 | "I Don't Care" Filter — items ranked A/B/C, not all equal? |
