To test the bandwidth and latency of a Thunderbolt Bridge between two Macs using `iperf3`, you can follow the steps below.

### Expected Performance
*   **Throughput:** A properly configured Thunderbolt Bridge typically achieves speeds between **15 Gbps and 35+ Gbps**, depending on the Thunderbolt generation (TB3 vs. TB4/USB4) and the specific hardware involved[1][2][3].
*   **Troubleshooting:** If you see lower-than-expected speeds, it is often due to the OS routing traffic through other network interfaces (like Wi-Fi or Ethernet) instead of the Thunderbolt Bridge[1][4]. Some users report better results by temporarily disabling other network connections during the test[1][5].

---

### Step-by-Step Testing Guide

#### 1. Install iPerf3
If you do not have `iperf3` installed, the easiest way to get it on macOS is via [Homebrew](https://brew.sh/):
```bash
brew install iperf3
```

#### 2. Configure the Thunderbolt Bridge
1.  Connect the two Macs using a certified Thunderbolt cable[4].
2.  Go to **System Settings > Network** on both Macs.
3.  Locate the **Thunderbolt Bridge** service. Ensure it is "Connected" (green)[1].
4.  Assign a static IP address to the Thunderbolt Bridge interface on both machines (e.g., `10.0.0.1` on Mac A and `10.0.0.2` on Mac B) to ensure traffic is forced over the bridge[2].

#### 3. Run the iPerf3 Test
Choose one Mac to act as the **server** and the other as the **client**.

*   **On the Server Mac:**
    Open Terminal and run:
    ```bash
    iperf3 -s
    ```

*   **On the Client Mac:**
    Open Terminal and connect to the server's Thunderbolt IP address:
    ```bash
    iperf3 -c 10.0.0.1  # Replace with the actual IP of your server Mac
    ```

#### 4. Advanced Testing Options
*   **Bidirectional Test:** To test upload and download simultaneously, add the `-d` flag[6]:
    ```bash
    iperf3 -c 10.0.0.1 -d
    ```
*   **Change Duration:** The default test lasts 10 seconds. Use the `-t` flag to extend it (e.g., for 30 seconds)[2][6]:
    ```bash
    iperf3 -c 10.0.0.1 -t 30
    ```

### Why File Transfers Might Be Slower
It is common for `iperf3` to report speeds (e.g., 30+ Gbps) that are significantly higher than actual file transfer speeds (SMB/File Sharing)[1][3]. File transfer performance is often limited by the storage drive’s read/write speeds, the file system overhead, and the protocol (SMB) rather than the Thunderbolt link itself[3].
