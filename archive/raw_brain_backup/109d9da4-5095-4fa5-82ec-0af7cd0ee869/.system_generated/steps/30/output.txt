The search for ""Apple Silicon" eGPU external GPU support dropped macOS" returned the following summary:
Apple Silicon Macs (M1, M2, M3, M4, and newer) **do not support external GPUs (eGPUs) for graphics acceleration**[1][2][3]. 

When Apple transitioned from Intel-based Macs to its own Apple Silicon architecture, it officially dropped support for eGPUs[3][4][5]. Unlike Intel Macs, which utilized Thunderbolt to offload graphics processing to an external card, Apple Silicon's architecture relies on a highly integrated "Unified Memory" system that is not designed to interface with external graphics hardware in the same way[1][6].

### Important Nuance: "Compute" vs. "Graphics"
In April 2026, there were reports that Apple approved a driver from *Tiny Corp* (the team behind tinygrad) that allows certain AMD and Nvidia eGPUs to be recognized by Apple Silicon Macs[7][8][5]. However, it is critical to understand the limitations of this development:

*   **Compute Only:** This support is strictly for **compute tasks** (such as AI workloads, machine learning, and data processing)[9][8][3].
*   **No Graphics/Gaming:** The driver does **not** provide graphics acceleration[9][2]. It will not improve performance for gaming, 3D modeling, video editing, or external display output[9][3]. 
*   **Not a Return to eGPU Support:** This is considered a specialized, narrow implementation for AI/compute rather than a return to the broader eGPU ecosystem that existed for Intel Macs[6].

In summary, if you are looking for an eGPU to boost gaming performance or support additional monitors on an Apple Silicon Mac, there is currently no official or practical solution to achieve this[1][3].
