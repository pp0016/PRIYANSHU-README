The memory architecture of the M1 Pro, M1 Max, and M1 Ultra chips in the Apple Silicon family utilizes LPDDR5 memory[1][2][3] with distinct bus widths to achieve their respective memory bandwidths.

### **Memory Specifications**

| Chip | Memory Bus Width | Memory Bandwidth |
| :--- | :--- | :--- |
| **M1 Pro** | 256-bit[1][4] | Up to 200 GB/s[1][5] |
| **M1 Max** | 512-bit[1][4] | Up to 400 GB/s[6][5] |
| **M1 Ultra** | 1024-bit (aggregate)*[7] | Up to 800 GB/s[8][7] |

*\*Note: The M1 Ultra is essentially two M1 Max dies interconnected[9][10], effectively doubling the memory bus width and bandwidth of a single M1 Max[7].*

### **Key Architectural Details**
*   **Memory Type:** The M1 Pro, M1 Max, and M1 Ultra use **LPDDR5** memory[1][2]. (The original M1 used LPDDR4X[11][12]).
*   **UltraFusion:** This is Apple's custom packaging architecture used to connect two M1 Max dies to create the M1 Ultra[9][13]. It provides a massive **2.5 TB/s** of low-latency inter-processor bandwidth[7][13][14], allowing the two dies to communicate and access unified memory as a single SoC[14]. 
*   **Unified Memory:** Because these chips use a unified memory architecture, the high bandwidth is shared between the CPU, GPU, and Neural Engine[9][2]. This design is a significant factor in the performance of Apple Silicon, as it provides GPU-level memory bandwidth to the entire system[2][5].
