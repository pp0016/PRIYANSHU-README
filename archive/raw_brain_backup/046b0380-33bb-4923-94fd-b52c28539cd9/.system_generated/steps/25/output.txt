To run a 27B parameter model (such as Gemma 3 27B or similar dense models like Qwen 27B/3.8-27B) on a system with 12GB of VRAM, you must use quantization and often rely on CPU offloading.

### VRAM Requirements Summary
*   **Model Weights:** A 27B model at **Q4_K_M quantization** typically requires approximately **15GB–17GB** of memory just for the weights[1][2][3].
*   **The 12GB Constraint:** Because the model weights alone exceed 12GB, you cannot fit the entire model into VRAM[4][3].
*   **Practical Inference:** To run it on a 12GB GPU, you must use inference engines like `llama.cpp` to offload a portion of the model layers to your system RAM (CPU)[4][5][6].

### How to Run on 12GB VRAM
1.  **Partial Offloading:** Use `device_map="auto"` (in Hugging Face `transformers`) or the `-ngl` (number of GPU layers) flag in `llama.cpp`[4][6]. You will load as many layers as fit into your 12GB of VRAM and keep the remainder in system RAM[4][6].
2.  **Performance Trade-off:** When layers are offloaded to the CPU, inference speed will decrease significantly (often to 3–10 tokens per second, depending on your CPU and RAM speed)[7][8][6].
3.  **Quantization Levels:**
    *   **Q4_K_M (Recommended):** The "sweet spot" for balance between quality and size, though it will require CPU offloading on a 12GB card[2][6].
    *   **Lower Quants (IQ3/IQ2):** If you are desperate to keep more layers in VRAM, you may experiment with lower quantization levels (e.g., Q3_K_M or IQ2/IQ3), though this will result in a noticeable drop in model intelligence[7][5][9].
4.  **KV Cache & Context:** Remember that the Key-Value (KV) cache grows with context length[10]. If you run out of memory, reducing the context window (e.g., from 128k to 8k or 32k) is often more effective than lowering the quantization further[7][11][12].

### Recommendations
*   **Use `llama.cpp`:** It is currently the most robust tool for managing partial GPU/CPU offloading for GGUF models[4][13].
*   **Monitor VRAM:** Use tools like `nvidia-smi` to ensure you are not exceeding your 12GB limit, which would trigger aggressive swapping and extremely slow speeds[4][6].
*   **Optimize:** If you have 32GB+ of system RAM, the performance penalty of offloading will be manageable for non-real-time tasks[4][6]. If you require high speed, you may need to look at smaller models (e.g., 12B class) which fit comfortably into 12GB VRAM[10][2][14].
