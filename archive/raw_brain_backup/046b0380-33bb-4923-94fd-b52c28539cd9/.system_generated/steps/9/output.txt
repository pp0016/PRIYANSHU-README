### **Key Factors for 2025/2026 Local Inference**
*   **Quantization (GGUF/EXL2/AWQ):** This is essential for running larger models on consumer hardware. 4-bit quantization is the "sweet spot" for most users, offering a high performance-to-memory ratio with minimal quality loss.
*   **Context Length (KV Cache):** As context windows grow (e.g., 32k, 128k), the KV cache can consume significant VRAM—sometimes more than the model weights themselves. If you experience "Out of Memory" (OOM) errors, reducing the context length is the first step.
*   **Unified Memory (Apple Silicon):** Mac users with M2/M3/M4 Max/Ultra chips benefit from Unified Memory, which allows the GPU to share system RAM. This makes running large models (like the 671B DeepSeek-R1) possible without expensive multi-GPU server setups, though inference speeds will be lower than dedicated NVIDIA H100/RTX 4090/5090 clusters.
*   **Hardware Recommendations:** 
    *   **Entry Level (8GB VRAM):** Suitable for 7B/8B models (Mistral 7B, DeepSeek 8B).
    *   **Enthusiast (24GB VRAM - e.g., RTX 3090/4090):** The "gold standard" for local LLMs, capable of running 32B–46B parameter models effectively.
    *   **Professional/Workstation (48GB+):** Required for 70B+ models or long-context agentic workflows.
