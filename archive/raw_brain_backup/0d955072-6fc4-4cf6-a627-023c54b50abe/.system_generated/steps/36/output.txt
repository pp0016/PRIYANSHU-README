**Movis** is a Python library designed for programmatic video editing and production[1][2]. It is intended to provide features typically found in proprietary desktop video editing software—such as compositions, keyframe-based animations, and various effects—within a code-based environment[3][4].

### Key Features
*   **Compositions:** Uses compositions as the fundamental unit, allowing for nested compositions to handle complex editing tasks[3][5].
*   **Animation & Effects:** Supports keyframe animations, chroma key, drop shadows, and multiple blending modes[3][4].
*   **Performance:** Includes a caching mechanism to speed up frame rendering[3].
*   **Use Cases:** Suitable for motion graphics, presentation video generation, shader art, and automated video production (e.g., game commentary or data-driven videos)[1][2].

### Example Usage
Movis allows you to define video elements and their properties directly in Python[5][6]:

```python
import movis as mv

# Create a composition
scene = mv.layer.Composition(size=(1920, 1080), duration=5.0)

# Add a background
scene.add_layer(mv.layer.Rectangle(scene.size, color='#fb4562'))

# Add text with animation
scene.add_layer(
    mv.layer.Text('Hello World!', font_size=256, color='#ffffff'),
    name='text', offset=1.0)

# Apply effects and motion
scene['text'].add_effect(mv.effect.DropShadow(offset=10.0))
scene['text'].opacity.enable_motion().extend([0.0, 1.0], [0.0, 1.0])

# Render the video
scene.write_video('output.mp4')
```
