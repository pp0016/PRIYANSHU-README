The **parallax-maker** repository, owned by **provos** (Niels Provos), is an open-source tool designed to transform static images into 2.5D animations[1][2][3].

### **Repository Information**
*   **GitHub URL:** [https://github.com/provos/parallax-maker](https://github.com/provos/parallax-maker)[1][3]
*   **Purpose:** Provides a workflow for image segmentation, depth map generation (using models like MiDaS or DINOv2), inpainting (with support for Stable Diffusion, Automatic1111, or ComfyUI), and 3D scene export to glTF format for use in tools like Blender or Unreal Engine[1][4][5].
*   **Last Updated:** The repository remains active, with recent maintenance including updates to packaging and dependencies[6][7]. Releases have been documented as recently as June 2025[8][9].
*   **README:** The project includes a comprehensive `README` (as well as a `CLAUDE.md` file) that covers installation prerequisites (Python 3.10+), setup instructions, and usage for its Web UI[6][4][7].

### **Key Features**
*   **Segmentation:** Uses the Segment Anything Model (SAM) with point selection[1][4].
*   **Inpainting:** Supports replacing masked regions via various image generation models[1][5].
*   **3D Export:** Generates glTF scenes with support for depth displacement[1][4].
*   **Interface:** Features a Python-based Dash web UI[3][4].
