In MoviePy, adding sound effects (SFX) to a video or animation is typically handled by creating an `AudioFileClip` object and compositing it with your video or animation sequence[1][2].

### Core Concepts for Adding SFX
*   **Audio Clips:** MoviePy treats audio as objects (`AudioFileClip`) separate from video objects (`VideoFileClip` or others)[2]. To add a sound effect, you load the audio file and then mix it with your video's existing audio or set it as the audio for the clip[1][2].
*   **Compositing:** You use `CompositeAudioClip` to layer multiple sounds (e.g., background music + specific sound effects) and then use `.with_audio()` (or `.set_audio()` in v1.x) to attach the final audio object to your video clip[1][2].

### Typical Workflow
1.  **Load Assets:** Load your video/animation and your sound effect file[1][2].
    ```python
    from moviepy import VideoFileClip, AudioFileClip, CompositeAudioClip

    video = VideoFileClip("animation.mp4")
    sfx = AudioFileClip("pop.wav").with_start(2) # Start at 2 seconds
    ```
2.  **Mix Audio:** Combine the SFX with the existing audio (if any) using `CompositeAudioClip`[2].
    ```python
    final_audio = CompositeAudioClip([video.audio, sfx])
    ```
3.  **Attach and Export:** Apply the audio to the video and write the file[1][2].
    ```python
    final_video = video.with_audio(final_audio)
    final_video.write_videofile("output.mp4")
    ```

Several open-source projects on GitHub use MoviePy to automate video creation and integrate SFX/audio:
*   [**AI-Microdrama-Factory**](https://github.com/SDSmirnov/AI-Microdrama-Factory): Uses MoviePy, pydub, and ElevenLabs for text-to-speech and sound effect integration in automated video pipelines[3][4].

*   [**MovieLite**](https://github.com/francozanardi/movielite): A performance-focused alternative to MoviePy that follows a similar object-oriented approach for video and audio editing[7].

*Note: MoviePy v2.0+ has introduced breaking changes compared to v1.x (e.g., using `with_audio()` instead of `set_audio()`). Ensure your code matches the version you have installed[1].*
