Below are the GitHub repositories and project details for **Sketch2Motion** and **PhysGen**.

### **1. Sketch2Motion**
There are two distinct projects often referred to by this name:

*   **Sketch2Motion (Animation Tool):** A tool to convert photos or sketches into animated MP4 videos using Manim.
    *   **GitHub Repository:** [leeyeel/Sketch2Motion](https://github.com/leeyeel/sketch2motion)
    *   **Description:** This project takes a doodle or photo, converts it into an SVG vector graphic, and renders it into a smooth drawing animation. It includes a Gradio web interface and allows for customizable animation styles and parameters[1][2].
*   **Sketch2Motion (Research - Skeleton Optimization):** A research project titled *"Sketch2Motion: Text-driven 2D Sketch to 3D Animation via Diffusion-guided Skeleton Optimization."*
    *   **Details:** This framework uses diffusion models and skeleton optimization to animate 2D sketches. It is associated with researchers Gaurav Rai and Ojaswa Sharma[3][4]. You can find project pages and academic publications via ResearchGate or the authors' personal pages, though the code is often linked within their specific research repository collections[5][4][6].

### **2. PhysGen**
There are also two prominent projects under the name **PhysGen**:

*   **PhysGen (Rigid-Body Physics-Grounded Image-to-Video Generation):**
    *   **GitHub Repository:** [stevenlsw/physgen](https://github.com/stevenlsw/physgen)
    *   **Description:** This project (ECCV 2024) focuses on image-to-video generation that is physically plausible. It integrates model-based physical simulation with data-driven video generation to produce videos where objects behave realistically according to forces and torques[7][8][9].
*   **PhysGen (Physically Grounded 3D Shape Generation):**
    *   **GitHub Repository:** [kasvii/PhysGen](https://github.com/kasvii/PhysGen)
    *   **Description:** A framework (CVPR 2026) for industrial design that models geometry and physical properties in a shared latent space to generate 3D shapes that are both aesthetically and physically valid (e.g., aerodynamic cars)[10][11].
