## 6. Key Formulas / Lists to Memorize

> [!NOTE]
> This is a THEORY-heavy subject. No complex formulas — just key lists and definitions to memorize.

### Must-Know Lists:

**1. Therbligs (Memorize any 8):**
| Therblig | Symbol | Abbreviation |
|----------|--------|:---:|
| Search | Eye turned | Sh |
| Select | Reaching to object | St |
| Grasp | Hand open | G |
| Transport Loaded | Magnet on bar | TL |
| Transport Empty | Hand without object | TE |
| Hold | Magnet | H |
| Release Load | Drop from hand | RL |
| Position | Object placed | P |
| Inspect | Magnifying glass | I |
| Assemble | Several things together | A |
| Disassemble | One taken from several | DA |
| Use | Word "Use" | U |

**2. Principles of Motion Economy (3 Categories):**
- Use of Human Body (symmetrical hand motions, minimize movements, use momentum)
- Arrangement of Workplace (fixed positions for tools, gravity feed, proper lighting)
- Design of Tools & Equipment (combine tools, pre-position tools, distribute load among fingers)

**3. DMAIC (Six Sigma):**
- **D**efine → **M**easure → **A**nalyze → **I**mprove → **C**ontrol

**4. Process Chart Symbols:**
- ⭕ Operation | ➡️ Transport | ▽ Storage | □ Inspection | D Delay
