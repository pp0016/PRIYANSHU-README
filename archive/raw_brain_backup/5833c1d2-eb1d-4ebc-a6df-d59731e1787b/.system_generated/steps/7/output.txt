**Inkplainer-OS** is an open-source, free-to-use whiteboard animation maker that runs entirely within a web browser[1][2].

### Key Features
*   **Privacy-Focused:** The tool is designed to be private by default. It has no backend or servers; all processing, including image/text uploading and video rendering, happens locally on your device[1][3][4].
*   **No Sign-up/Cost:** It is free, requires no account, and adds no watermarks to your exports[1][2].
*   **Animation Modes:**
    *   **Animation Mode:** A basic hand-drawn style that allows control over direction and hand behavior[3][5].
    *   **Drawing Mode:** A more advanced mode that redraws images stroke-by-stroke, offering control over outline styles, stroke behavior, and colors[3][6].
*   **Export Options:** You can export your creations as MP4 or WebM videos (up to 1440p) or as a static PNG of the final frame[1][7].
*   **Tools:** It includes a "Slicer" tool for cutting images into independent animated layers and a "Coordinate Mapper Tool" to configure hand graphics[1][8].

### Getting Started
Because it is a static web-based tool, you can run it by cloning the repository and serving the files locally[1][7]:

```bash
# Clone the repository
git clone https://github.com/NadirWeb-App/Inkplainer-OS.git
cd inkplainer

# Serve using a static server (e.g., npx)
npx serve .
# Or use Python
python3 -m http.server 8080
```

Once running, you can access the interface through your browser at the specified local address (e.g., `http://localhost:8080`)[1][7]. You can find the project on GitHub under the user **NadirWeb-App**[9][10].
