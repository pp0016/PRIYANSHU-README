**anything2explainer** is an open-source tool and skill designed for **Claude Code** and **Codex** that automates the creation of narrated, motion-graphics explainer videos[1][2].

### Key Features
*   **Workflow:** You provide a topic, and the tool produces a complete explainer video including a narration script, text-to-speech (TTS) voiceover, subtitles, and a chapter progress bar[1][2].
*   **Visual Style:** Instead of using stock footage or generative video models, every frame is programmatically drawn using **Remotion** (React + TypeScript)[1][2]. The aesthetic features a black canvas with white line art, bold headlines, and a star-field or dot-field backdrop[2].
*   **Bilingual Support:** It supports both English and Chinese narration[1][2].
*   **Pipeline:** The tool handles the full production pipeline: research and scriptwriting, voiceover generation, storyboard creation, parallel shot building, and quality control reviews[2].

### How It Works
*   **Technology Stack:** It utilizes Remotion for video rendering, Node.js, and various TTS engines (such as `edge-tts` for Chinese and `kokoro` for English)[3][2].
*   **Installation:** It is designed to be added as a skill for agentic CLI tools like Claude Code or Codex[3][2]. Users typically clone the repository and link it to their local skills directory[1][2].
*   **License:** The project is released under the **PolyForm Noncommercial license**, meaning it is suitable for personal projects but not for commercial use[4][2].

You can find the project on GitHub under the username **Vincentwei1021**[5].
