To connect two Mac computers using Thunderbolt Bridge, you can use a Thunderbolt cable to establish a direct network connection between them[1][2].

### Steps to Connect Two Macs via Thunderbolt Bridge
1.  **Physical Connection:** Connect a Thunderbolt cable to the Thunderbolt ports on both Mac computers[3][2].
2.  **Access Network Settings:** On each Mac, go to the **Apple menu > System Settings**, then click **Network** in the sidebar[3][4].
3.  **Configure Thunderbolt Bridge:**
    *   Look for the **Thunderbolt Bridge** service in the list[1][3].
    *   If it is not visible, you may need to add it (refer to your Mac's "Set up a network service" help documentation)[1][3].
    *   Click **Thunderbolt Bridge**, then click **Details**[1][3].
    *   By default, the computers should receive IP addresses automatically using DHCP[2][5]. If you need to set them manually, you can click **TCP/IP** and configure the IPv4 settings accordingly[1][3].
4.  **Transfer Files:**
    *   Once connected, open a **Finder** window[6].
    *   Click **Network** under **Locations** in the Finder sidebar[6].
    *   Double-click the icon for the other Mac and select **Connect As** to proceed with file sharing[6]. 
    *   *Note: Ensure that File Sharing is enabled on the Mac you are trying to access if it does not appear in the network list[6].*
