High Performance Screen Sharing is a feature in macOS that provides improved responsiveness and supports advanced workflows such as HDR video reference modes, stereo audio, 4:4:4 chroma subsampling, and high frame rates (30 or 60 fps)[1][2].

### Requirements and Limitations
*   **Hardware & Software:** Both the controlling Mac and the remote Mac must be Apple silicon models running macOS Sonoma 14 or later[1][2].
*   **Network:** Requires high bandwidth (recommended 75 Mbps for a single 4K display) and consistent low network latency[1][2]. A wired network connection is recommended[1][2].
*   **Connectivity:** Both computers must be able to communicate over UDP ports 5900, 5901, and 5902[1][2].
*   **Session Limits:** Only one High Performance session can be active on a Mac at a time[1][2].
*   **Display:** The maximum supported resolution for a virtual display is 4K[1][2].

### Key Behaviors
*   **Privacy:** If you sign in using the user account currently logged into the target Mac, the hardware displays connected to that Mac will be blanked, ensuring privacy[1][2]. This also prevents anyone else from using the target Mac while the session is active[1][2].
*   **Ending Sessions:** If you are controlling a Mac with Screen Sharing turned on, you can end the session by pressing the Escape key on a keyboard connected to the remote Mac (this does not apply when using Remote Management)[1].
*   **Configuration:** High Performance mode leverages the Mac's media engine to provide a fluid experience, making it suitable for tasks like scrubbing through video or working on complex 3D models[3][4].
