To transcode batches with multiple computers in Apple Compressor, you use **distributed processing**. This feature allows you to decrease transcoding time by sharing the workload across multiple Macs on your network[1][2].

### Requirements
*   **Software:** All computers must have the same version of Compressor installed and be running the same version of macOS[1][3].
*   **Network:** All computers must be on the same network[1].
*   **Status:** Compressor must be open and running on every computer in the group[1][3].

### Step 1: Make Computers Available for Sharing
On each Mac you intend to use as a "node" (a computer that will help process the files):
1.  Open **Compressor**.
2.  Choose **Compressor > Settings** (or Preferences)[1][4].
3.  Select the **My Computer** tab[1][5].
4.  Check the box for **"Allow other computers to process batches on my computer"**[1][5].
5.  *(Optional)* Select **Require Password** if you want to control access with a password[1][5].

### Step 2: Create a Shared Computer Group
On the main Mac you are using to control the batch:
1.  Go to **Compressor > Settings** and select the **Shared Computers** tab (or similar "Shared" section)[6].
2.  Click the **add button (+)** to create a new group[6].
3.  Name the group (e.g., "Rendering Cluster")[6].
4.  In the list of available computers on the right, select the checkboxes for all the Macs you want to include in this group[6].

### Step 3: Run the Batch
1.  Set up your transcoding job in the **Batch** pane as you normally would[6][7].
2.  Before clicking **Start Batch**, look for the **"Process on"** pop-up menu at the bottom of the batch area[6][3].
3.  Choose the **shared computer group** you created[6][3].
4.  Click **Start Batch**[6][3]. Compressor will now distribute the files in your batch among the selected computers[1][2].

### Troubleshooting
*   **If you cannot see other computers:** Ensure they are all on the same network and that Compressor is actively open on those machines[1].
*   **macOS Permissions:** If you are having trouble on newer macOS versions (like Catalina or later), ensure you have granted the necessary network/folder access permissions in **System Preferences > Security & Privacy > Privacy**[8][9].
*   **Additional Instances:** Within the **Advanced** settings of Compressor, you can also "Enable additional Compressor instances" to further utilize your computer's own processing cores, which can be used in tandem with distributed processing[6][10][4].
