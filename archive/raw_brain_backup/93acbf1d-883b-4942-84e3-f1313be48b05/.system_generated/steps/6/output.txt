To connect two Mac computers using Thunderbolt, there are two primary methods depending on your goal: **Target Disk Mode** (for file transfers) or **Thunderbolt Bridge** (for a network connection).

### 1. Target Disk Mode (For File Transfers)
Target Disk Mode allows you to use one Mac as an external hard drive for another, which is a common and fast way to move large amounts of data.

*   **Requirements:**
    *   Two Mac computers.
    *   A Thunderbolt cable.
    *   **Important:** If either Mac is running macOS Big Sur (11.0) or later, you **must** use a Thunderbolt cable; USB-only cables will not work for this mode[1][2][3].
*   **How to do it:**
    1.  Connect the two Macs using the Thunderbolt cable[4][2].
    2.  If the Mac to be used as the disk is an **Intel-based Mac**:
        *   Shut down the Mac.
        *   Turn it on while holding down the **T** key[5][2].
    3.  If the Mac is an **Apple silicon Mac**, it uses "Mac Sharing Mode," which is accessed via macOS Recovery[2][6].
    4.  The Mac should appear as an external disk icon on the desktop of the other computer, allowing you to drag and drop files[7].

### 2. Thunderbolt Bridge (For Network Connection)
If you want to connect two Macs to communicate with each other over a network connection (e.g., for file sharing or other IP-based services), you can use Thunderbolt Bridge.

*   **How to set it up:**
    1.  Connect both Macs with a Thunderbolt cable[8].
    2.  On both Macs, go to **System Settings** (or System Preferences) > **Network**[8].
    3.  Look for **Thunderbolt Bridge** in the list of services[8].
    4.  Ensure the interface is active[8]. Once connected, the Macs can communicate over this interface as if they were on a local network[9].
    *   *Note:* Even when physically connected, macOS may sometimes default to Wi-Fi or Ethernet if they are faster or prioritized. Ensure your network settings are configured correctly to prefer the Thunderbolt Bridge if you intend to use it for high-speed transfers[9].

### Summary of Differences
| Feature | Target Disk Mode | Thunderbolt Bridge |
| :--- | :--- | :--- |
| **Primary Use** | Direct file transfers / Migration | Networking / IP communication |
| **Setup** | Requires booting into a special mode | Runs while macOS is active |
| **Behavior** | One Mac acts as an external drive | Macs act as two devices on a network |
