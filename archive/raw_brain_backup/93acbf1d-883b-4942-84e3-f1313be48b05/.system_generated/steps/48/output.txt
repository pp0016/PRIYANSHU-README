Apple Silicon does not currently support the use of CXL (Compute Express Link) or Thunderbolt to expand system RAM[1].

### Unified Memory Architecture (UMA)
The core of Apple Silicon's performance and efficiency is its **Unified Memory Architecture (UMA)**[2][3]. In this design:
*   **Integration:** The RAM is soldered directly onto the same package as the CPU and GPU (System-on-a-Chip)[2][4].
*   **Cache Coherency:** Because the CPU, GPU, and Neural Engine share the same memory pool, they can access the same data without needing to copy it between separate pools (e.g., from system RAM to dedicated VRAM)[5][3][6]. This shared pool maintains cache coherency through high-bandwidth, low-latency channels integrated directly into the silicon[5][7].
*   **Non-Expandability:** Because the memory must be physically adjacent to the chip to achieve these high-speed, low-latency data transfers, it cannot be expanded or "combined" with external memory via external ports like Thunderbolt[4][1][8].

### Why Thunderbolt/CXL Doesn't "Combine" RAM
*   **Architectural Limitations:** While Thunderbolt provides high-speed data transfer (up to 80Gbps or more on newer versions), it is a PCIe-based interface[9]. The Apple Silicon bus fabric and memory subsystem are designed for the extremely high-bandwidth, low-latency requirements of internal LPDDR memory[10][1][11]. 
*   **Latency Barriers:** External memory connected over PCIe or Thunderbolt would introduce significant latency compared to the onboard unified memory[1]. The system expects memory to be mapped in a specific way that is incompatible with the "hot-pluggable" or external nature of Thunderbolt devices[1].
*   **CXL:** While CXL is an industry standard designed for memory expansion and cache coherency over PCIe, it is not currently implemented in a way that allows consumer Apple Silicon Macs to treat external CXL devices as additional system RAM[10][1].

In summary, the memory in an Apple Silicon Mac is a fixed, tightly coupled resource. It provides significant performance benefits specifically *because* it is integrated, which inherently prevents it from being upgraded or pooled with external memory devices[3][8][12].
