## Which macOS will be installed?
On a [Mac with Apple silicon](https://support.apple.com/en-in/116943):
- Recovery installs the current version of the most recently installed macOS.
- If you installed a macOS upgrade and then [used Disk Utility to erase the disk](https://support.apple.com/en-in/102506), you may get the macOS that you were using before upgrading.
Recovery installs the current version of the most recently installed macOS.

On any other Mac:
- If you used Command-R to start up from the local Recovery system, you get the current version of the most recently installed macOS.
- If you used Option-Command-R to start up from Internet Recovery, you may get the latest macOS that is compatible with your Mac. 
- If you used Shift-Option-Command-R to start up from Internet Recovery, you may get the macOS that came with your Mac, or the closest version still available.

## If you can’t reinstall macOS
- If the installer doesn't see your disk, quit the installer, choose Disk Utility from the list of options in Recovery, then [use Disk Utility to erase your startup disk](https://support.apple.com/en-in/102506). If Disk Utility can’t see the disk or erase it, your Mac may need to be serviced.
- [Find out what to do if an error occurs during installation](https://support.apple.com/en-in/102531). To install macOS from Recovery, your Mac must have a broadband internet connection that uses DHCP over Wi-Fi or Ethernet. Some network connections can prevent installation from Recovery, including those that use a required captive-network login, 802.1X security or PPPoE (unless a router is handling the PPPoE connection).
- [Find out what to do if your Mac doesn’t start up all the way](https://support.apple.com/en-in/102675) before or after installation.
- [Find out other ways to install macOS](https://support.apple.com/en-in/102662).
