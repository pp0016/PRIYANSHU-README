# 🚀 How to Use Opus 4.5 & All Models via 9Router

9Router is a **local AI proxy server** running at `http://localhost:20128`. It lets you connect multiple AI providers and route their models through a single endpoint — so your coding tools (Antigravity, Claude Code, Cursor, Copilot, etc.) can access **any model from any provider**.

---

## How It Works (The Big Picture)

```
Your Coding Tool (e.g. Antigravity)
        ↓ sends request to
  9Router (localhost:20128)
        ↓ routes to
  Connected Provider (e.g. Claude Code, Anthropic, OpenRouter...)
        ↓ calls
  AI Model (e.g. Opus 4.5, Sonnet 5, GPT-4o...)
```

---

## Step 1: Start 9Router

Open PowerShell and run:
```powershell
9router
```
Your dashboard opens at: **http://localhost:20128/dashboard**

---

## Step 2: Connect a Provider

You need to connect **at least one provider** that gives you access to the models you want. Here's how to get **Opus 4.5** based on your options:

### Option A: Claude Code (OAuth — uses your existing subscription) ⭐ Recommended
1. Go to **Dashboard → Providers → Claude Code**
2. Click **"+ Add Connection"**
3. It will open an OAuth login — sign in with your Anthropic/Claude account
4. Once connected, you get access to: `claude-opus-5`, `claude-sonnet-5`, `claude-haiku-4.5`, etc.

> [!IMPORTANT]
> The dashboard shows a risk notice: *"This provider uses a subscription/OAuth session not officially licensed for proxy/router use."* This means Anthropic could restrict accounts used this way. Use at your own risk.

### Option B: Anthropic (API Key — pay-per-token)
1. Go to **Dashboard → Providers → Anthropic**
2. Click **"+ Add Connection"**
3. Enter your Anthropic API key (get one from [console.anthropic.com](https://console.anthropic.com))
4. This gives you access to all Claude models including Opus

## Step 3: Get Your 9Router Endpoint & API Key

After connecting a provider:
1. Go to **Dashboard → Endpoint & Key** (first item in sidebar)
2. Copy your:
   - **Endpoint URL**: `http://localhost:20128/v1`
   - **API Key**: (auto-generated by 9Router)

---

## Step 4: Use Models in Your Coding Tools

### In Antigravity (this tool)
Set these in your Antigravity settings or environment:
- **API Endpoint**: `http://localhost:20128/v1`
- **API Key**: (paste from dashboard)
- **Model**: Use the model ID from the provider, e.g.:
  - `cc/claude-opus-5` (Claude Opus via Claude Code provider)
  - `cc/claude-sonnet-5` (Sonnet via Claude Code)
  - `cc/claude-haiku-4-5-20251001` (Haiku 4.5 via Claude Code)

### In Claude Code CLI
```bash
export ANTHROPIC_BASE_URL=http://localhost:20128/v1
export ANTHROPIC_API_KEY=your-9router-key
claude
```

### In Cursor IDE
Go to Settings → Models → Add custom endpoint:
- Base URL: `http://localhost:20128/v1`
- API Key: your 9router key

### In any OpenAI-compatible tool
Just point the base URL to `http://localhost:20128/v1` with your 9router API key.

## Step 5: Advanced Features

### Round Robin (Multi-Account)
- Connect multiple accounts to the same provider
- Toggle **"Round Robin"** on the provider page
- 9Router will rotate between accounts to avoid rate limits

### Token Saver (RTK)
- Automatically compresses tool outputs to save 20-40% tokens
- Configure in **Dashboard → Settings**

### Auto-Fallback
- If one provider hits a rate limit, 9Router falls back to the next available one
- Set fallback order in **Dashboard → Proxy Pools**

### Quota Tracker
- Monitor token usage per provider in **Dashboard → Usage** and **Quota Tracker**
