**handanim** is an open-source Python library designed to programmatically generate **hand-drawn, sketch-style animations**[1][2]. It is particularly well-suited for creating instructional videos, educational content, visual explanations, and stylized presentations[1][2].

### Key Features
*   **Sketch-Style Animation:** Create animations for geometric shapes (lines, ellipses, polygons) that have a natural, hand-drawn feel[3].
*   **Styling Options:** Supports filling objects with sketch-style strokes, such as hatching or scribbles[3].
*   **Handwritten Text:** Animates text using custom fonts[3].
*   **Math Support:** Capable of rendering and animating mathematical expressions using TeX notation[4].
*   **Export Formats:** Allows for exporting content as vector images (SVG) or video files (MP4)[3].

### Technical Details & Getting Started
*   **Repository:** [github.com/subroy13/handanim](https://github.com/subroy13/handanim)[1][5]
*   **Documentation:** [subroy13.github.io/handanim](https://subroy13.github.io/handanim)[1]
*   **Dependencies:** The library requires **Cairo** (for graphics) and **FFmpeg** (for video encoding) to be installed on your system[4].
*   **Installation:** It can be installed using `pip` or `poetry`[4].

The project is maintained by Subhrajyoty Roy, who also develops other tools such as `decompy` (matrix decomposition) and `roufcp` (changepoint detection)[1][6]. The author is actively looking for contributions and feedback from the community[1].
