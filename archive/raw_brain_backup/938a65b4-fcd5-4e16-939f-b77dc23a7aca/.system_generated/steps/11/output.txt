The **`gnipbao/whiteboard-video-engine`** is a Python-based engine designed for creating whiteboard-style animation videos[1][2].

### Key Features
*   **Functionality:** It can convert images, SVGs, line art, or scripts into whiteboard hand-drawing animations[1][2].
*   **Components:** The engine provides the core rendering capabilities, CLI tools, model wrappers, testing, and documentation[1][3].
*   **Visual Styles:** The engine includes 30 built-in, versioned visual "recipes" or styles that control aspects like stroke detail, line width, fill textures, and drawing order[2][4]. These styles are categorized by levels such as `native`, `adaptive`, and `experimental` depending on their suitability for different types of input content[4].

### Ecosystem
This engine is often used in conjunction with the **`codex-whiteboard-video-skill`** repository[1][2]. While the engine handles the heavy lifting (rendering, stroke tracing, and composition), the "skill" repository provides the necessary wrapper scripts and integration instructions to allow systems like Codex to call the engine[1][3].

### Installation
To install the engine, you can use pip directly from GitHub:
```bash
python3 -m pip install "git+https://github.com/gnipbao/whiteboard-video-engine.git"
```

For development purposes, it is recommended to install it in editable mode:
```bash
python3 -m pip install -e /path/to/whiteboard-video-engine
```

For more detailed usage, including CLI commands like `render-photo` and how to integrate it with the Codex skill, you can refer to the official repository documentation[1][5].
