**GreaseWriter** is a Blender add-on created by `doakey3` designed for auto-animating Grease Pencil strokes and emulating the appearance of hand-drawn text[1][2].

### Key Features
*   **Hand-Drawn Emulation:** The tool creates animations that mimic the natural flow of writing[1][3].
*   **Reanimation:** It allows you to select existing Grease Pencil objects and automatically animate the strokes in the order they were created[3]. It includes pauses between strokes to make the animation feel more like genuine human writing, distinguishing it from the standard Blender "Build" modifier[3].
*   **Text Writing:** It features a UI within the scene properties window where you can input text or load a text file and use the "Write" function to generate the writing animation[4].

### Installation
1.  **Download:** Go to the [GreaseWriter GitHub repository releases page](https://github.com/doakey3/GreaseWriter/releases) and download the latest `.zip` file[5][6].
2.  **Install in Blender:**
    *   Open Blender and navigate to **Edit > Preferences > Add-ons**.
    *   Click **Install...** and select the downloaded `.zip` file[6].
    *   Enable the add-on by checking the box next to "Grease Writer" and ensure you click **Save Preferences**[6].
