## 3. Step-by-Step Workflow

### One-Time Setup (Day 1-3)

```
Step 1: Buy & install GTA 5 on PC (via Steam or Epic Games)
Step 2: Download & install Script Hook V + Script Hook V .NET
Step 3: Download & install OpenIV
Step 4: Install AddonPeds (for custom characters)
Step 5: Install Spider-Man script from JulioNIB (Patreon)
Step 6: Install additional superhero ped models (Spider-Man suits, Hulk, etc.)
Step 7: Install Menyoo Trainer for scene control
Step 8: Download custom map mods (rainbow bridges, ramps)
Step 9: Install OBS Studio for recording
Step 10: Test everything works — launch GTA 5 in OFFLINE mode
```

> [!WARNING]
> **ALWAYS play in Offline/Story Mode.** Using mods in GTA Online will get your account banned by Rockstar.

### Daily Video Production Workflow

```
Step 1: Choose trending topic/meme (check TikTok, YouTube trends)     [10 min]
Step 2: Set up the scene in GTA 5 (spawn characters, build course)     [30-60 min]
Step 3: Record gameplay from multiple angles using Rockstar Editor      [60-90 min]
Step 4: Record cinematic replays with camera angles                     [30-60 min]
Step 5: Import into DaVinci Resolve / CapCut                           [10 min]
Step 6: Edit — add music, trending audio, cuts, transitions             [60-90 min]
Step 7: Add thumbnail (screenshot from gameplay + text overlay)         [15-20 min]
Step 8: Upload to YouTube with SEO title + tags                         [10 min]
```

**Total time per video: 3-5 hours**

## 5. Risks & Warnings

### ⚠️ COPPA / Kids Content Risk
MARINARA's description says "not intended for children under 13" — but the content is clearly aimed at kids (Spider-Man, bright colors, simple gameplay). YouTube's COPPA rules mean:
- If marked as "for kids" → no comments, no notifications, lower ad revenue
- If NOT marked as "for kids" but clearly is → FTC fine risk
- MARINARA walks this line by adding the legal disclaimer

### ⚠️ Copyright Risk
- Spider-Man is owned by **Marvel/Sony** — using their character models without permission is technically copyright infringement
- GTA 5 modding is in a legal gray area — Rockstar generally tolerates single-player mods but could issue takedowns
- Most channels in this niche haven't been hit yet, but it's always a risk

### ⚠️ Low RPM
- At $1.98 RPM, you need **massive volume** to make real money
- MARINARA needs 37.9M views/month to make $74K
- A smaller channel with 100K views/month at this RPM = only $198/month

### ⚠️ Algorithm Dependency
- This content type is heavily algorithm-dependent
- YouTube's algorithm pushes it to kids → massive views
- If YouTube changes how it surfaces kids content (like they did with Elsagate in 2017), views could collapse overnight
