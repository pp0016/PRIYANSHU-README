The repository **provos/parallax-maker** on GitHub is a tool designed to generate images that can be used for 2.5D animation[1][2].

### Key Features
*   **Workflow:** The tool provides a Dash-based Web UI that assists users in slicing images, inpainting those slices, and exporting them as a glTF scene[3]. 
*   **Integration:** These exported scenes can be used in software such as Blender or Unreal Engine[3]. The app also supports visualization of the generated scenes directly[3].
*   **API Support:** It supports Automatic1111 and ComfyUI API endpoints, allowing for remote GPU utilization, which can be useful for higher performance or using specialized inpainting models and workflows (such as those using offset LoRA)[4].
*   **Tools:** It includes command-line tools for manipulating the state files saved by the application[3].

### Installation
The project is built with Python and can be installed in development mode using `pip install -e .` within a virtual environment (Python 3.10+)[5].
