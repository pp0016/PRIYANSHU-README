In Manim, `ease_out_bounce` and `ease_out_back` are built-in rate functions used to control the speed and easing behavior of animations[1][2][3].

### How to use them
You can apply these functions by passing them to the `rate_func` argument within your `self.play()` method[1][3]:

```python
from manim import *

class EasingExample(Scene):
    def construct(self):
        circle = Circle().shift(LEFT * 3)
        square = Square().shift(RIGHT * 3)
        
        # Using ease_out_bounce
        self.play(circle.animate.shift(RIGHT * 6), rate_func=ease_out_bounce, run_time=2)
        
        # Using ease_out_back
        self.play(square.animate.shift(LEFT * 6), rate_func=ease_out_back, run_time=2)
```

### Key Differences
*   **`ease_out_bounce`**: Creates a "bouncy" effect as the animation reaches its end, simulating an object hitting a surface and bouncing[1][3].
*   **`ease_out_back`**: Creates a slight "overshoot" effect at the end of the animation, where the object moves slightly past its destination before settling back into position[1][3].

### Notes
*   **Availability**: These functions are exported by default in Manim, so you can use them directly without needing to prefix them with `rate_functions.`[4][5].
*   **Customization**: If you ever need to use a standard easing function that isn't exported directly, you can access it via the `rate_functions` module (e.g., `rate_func=rate_functions.ease_in_sine`)[4][6].
