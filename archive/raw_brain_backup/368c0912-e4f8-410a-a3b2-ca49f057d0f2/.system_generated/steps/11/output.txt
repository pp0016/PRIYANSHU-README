The **`masihsultani/whiteboard-animator`** is an open-source tool designed to automatically convert static whiteboard-style images into hand-drawn reveal animations[1][2][3].

Regarding your query about a **hand overlay**:

*   **Functionality:** This tool works by detecting regions in an image, determining the sequence in which they should be revealed, and animating them to simulate a "drawing" effect[2][3]. 
*   **Hand Overlay:** The project's primary focus is on the algorithmic "reveal" or sketch animation of the elements themselves[3]. Unlike commercial software such as VideoScribe, Doodly, or Moovly—which often include built-in, customizable "hand" assets that move across the screen to follow the drawing path—`masihsultani/whiteboard-animator` is a lightweight, local-running Python library/CLI tool[3][4][5][6]. 
*   **Current Status:** As of its recent release (September 2026), the project focuses on the core animation engine[1][2]. If you are looking for a visible hand cursor overlaying the drawing, you may need to:
    *   **Check the GitHub Repository:** Review the official [masihsultani/whiteboard-animator GitHub page](https://github.com/masihsultani/whiteboard-animator) to see if recent updates have added support for custom hand cursor overlays or if there is an open discussion about it[2][3].
    *   **Post-Processing:** If the tool does not currently render a hand, many users create this effect by running the generated animation through a video editor (like Adobe Premiere, DaVinci Resolve, or even free tools) and overlaying a transparent "hand" video file (often found in stock libraries or as "green screen" hand overlays) to follow the drawing path.
