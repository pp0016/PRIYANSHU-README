The `whiteboard-animator` project by **masihsultani** is an open-source tool designed to transform whiteboard-style images into hand-drawn reveal animations[1][2]. 

### Key Features
*   **Local Execution:** The tool runs locally on your CPU and does not require any API keys[3][4].
*   **Functionality:** It detects regions within an image, determines the optimal reveal order, and simulates the sketching process of a hand[3][4].
*   **Versatility:** It is provided as both a Python library and a command-line interface (CLI)[5][4].
*   **Licensing:** The project is MIT licensed[5][4].
*   **Best Use Cases:** It works most effectively with clean drawings on white backgrounds[5][4].
*   **Context:** It serves as the render engine behind **Kinoslide**[1][2].

You can access the project repository and its documentation on GitHub at: [https://github.com/masihsultani/whiteboard-animator](https://github.com/masihsultani/whiteboard-animator)
