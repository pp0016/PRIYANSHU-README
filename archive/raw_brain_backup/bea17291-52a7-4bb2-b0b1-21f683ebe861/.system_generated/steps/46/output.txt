Xgrid was a proprietary distributed computing technology developed by Apple's Advanced Computation Group[1][2]. Introduced in January 2004, it was designed to allow network administrators and researchers to harness the underutilized processing power of multiple Mac computers—turning them into a "virtual" supercomputer or computing cluster[1][3][2].

### How It Worked
Xgrid functioned on a client-server architecture to combine the processing power of multiple machines across a network[1][4]:
*   **Controller:** The central "brain" or job scheduler that managed the cluster[1][4]. It received jobs from a client, split them into smaller, manageable "tasks," and distributed these packets to available nodes[1][4].
*   **Agents (Nodes):** Individual Mac computers on the network that executed the instructions provided by the controller and returned the results[1][4].
*   **Client:** The interface (command-line or API) used by the user to submit and manage computational jobs[1][4].

The system leveraged technologies like **Bonjour** for automatic discovery of nodes, making it relatively easy to set up ad-hoc clusters[3][2]. It was particularly useful for "embarrassingly parallel" tasks—computations that could be easily divided into independent segments, such as rendering images, scientific simulations (e.g., gene sequencing with BLAST), or mathematical calculations like Mandelbrot maps[1][5][6].

### History and Legacy
*   **Availability:** Xgrid was integrated into Mac OS X versions 10.4 (Tiger) through 10.7 (Lion)[1]. The Xgrid controller was a feature of Mac OS X Server, though the agent software was included in standard versions of the operating system[1][7].
*   **Discontinuation:** Apple officially ended support for Xgrid with the release of OS X 10.8 (Mountain Lion) in 2012[1][8]. Apple declined to open-source the technology after its discontinuation[8].
*   **Modern Resurgence:** While Xgrid is long dead, the concept of clustering Mac hardware for parallel processing persists in niche communities[9][10]. Modern projects—such as those utilizing **MLX** and Thunderbolt networking—have emerged to link powerful, modern Macs (like Mac Studios) for similar distributed computing purposes, effectively reviving the promise of "home-grown" supercomputing[9][11].
