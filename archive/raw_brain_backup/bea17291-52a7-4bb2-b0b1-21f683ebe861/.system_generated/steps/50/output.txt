**Exo** (often associated with the GitHub organization **exo-explore**) is an open-source framework designed to enable **distributed inference** by clustering multiple consumer devices—such as Mac Minis, MacBooks, and other Apple Silicon Macs—into a single, unified AI inference engine[1][2][3].

### Key Concepts of Exo
*   **Distributed Inference:** Exo allows you to run large language models (LLMs) that are too big to fit into the memory (VRAM) of a single machine by splitting the model layers across multiple devices in your local network[4][5][2].
*   **Automatic Discovery:** The framework features peer-to-peer (P2P) device discovery, meaning you do not need to perform complex manual configurations to connect your Mac Mini and MacBook[4][6][3].
*   **Topology-Aware Partitioning:** It automatically analyzes the memory and network latency of each connected device to determine the most efficient way to partition the model[4][6][3].
*   **Performance Optimization:** 
    *   **MLX Backend:** It is optimized for Apple Silicon, utilizing the MLX framework for high-performance inference[7][6][2].
    *   **Tensor & Pipeline Parallelism:** By sharding models, Exo can achieve significant speedups (e.g., up to 3.2x on 4 devices)[7][6][8].
    *   **RDMA over Thunderbolt:** For newer hardware (e.g., devices with Thunderbolt 5), Exo supports Remote Direct Memory Access (RDMA) to drastically reduce latency between cluster nodes[6][9][2].
*   **API Compatibility:** It provides a ChatGPT-compatible API, allowing it to act as a drop-in replacement for existing AI tools, agents, and local AI workflows[4][2][3].

### Practical Setup
*   **Hardware:** You can mix and match Apple Silicon devices (M1/M2/M3/M4 series)[7][9]. While high-speed connections like Thunderbolt are recommended for best performance, the cluster will also work over standard Ethernet or Wi-Fi[7][10][11].
*   **Software:** Exo runs as a background app on macOS (or from source)[12][7]. Once installed on all nodes in your network, they automatically pool their collective memory to run frontier models[1][7][5].

By using Exo, developers and researchers can effectively build their own "AI supercomputer" at home or in an office, bypassing the need for expensive, single-unit high-end hardware by leveraging the combined resources of the machines they already own[7][5][13].
