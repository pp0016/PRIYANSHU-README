The search for ""TN3205" "RDMA over Thunderbolt"" returned the following summary:
**TN3205** is an official Apple Technote titled *"Low-latency communication with RDMA over Thunderbolt."*[1][2] It documents how to utilize **RDMA (Remote Direct Memory Access) over Thunderbolt** to enable high-performance, low-latency communication between clusters of Mac computers[1][3].

### Key Details
*   **Purpose:** The technology allows Mac computers (specifically Apple silicon models with Thunderbolt 5) to pool their resources—most notably unified memory—by enabling direct memory access between machines without involving the operating systems of the participants[4][5][6]. This is primarily targeted at distributed computing tasks, such as running large-scale AI models via tensor parallelism[7][8][9].
*   **Requirements:**
    *   **Hardware:** Requires Apple silicon Macs equipped with Thunderbolt 5[4][10].
    *   **Software:** Requires macOS 26.2 or later[4][10].
    *   **Configuration:** RDMA must be explicitly enabled on each machine via `rdma_ctl enable` in macOS Recovery mode[4][11][10].
*   **Use Cases:** It is widely used by the local LLM (Large Language Model) community (e.g., with tools like `llama.cpp` and `Exo`) to cluster multiple Mac Studios together[4][10][12]. By reducing network latency significantly—from hundreds of microseconds over standard networking to roughly 3 microseconds—it makes distributed inference feasible for models that exceed the memory capacity of a single machine[13][9].
*   **Limitations:** The implementation currently supports point-to-point connections and does not use standard network switches; therefore, clusters are typically limited to direct full-mesh wiring (e.g., up to four units)[11][14]. It is also noted that the standard macOS SMB (file sharing) stack does not utilize this RDMA fast path[15].
