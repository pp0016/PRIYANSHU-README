## Part 4: The 3-Tier Video Processing System (ADHD-Optimized)

### Tier 1 — Strategy/Talking Head (NotebookLM)
**Videos that are mostly someone talking to camera about concepts**
- Feed YouTube URL into NotebookLM
- Generate Audio Overview → download → play during **gym**
- After gym, open NotebookLM and do Q&A to test yourself
- Time: ~5 min setup, 0 min active watching, learning happens at gym
- **This alone turns 3 dead gym hours into learning time**

### Tier 2 — Visual Tutorials (Gemini 2.5)
**Videos where the VALUE is in what you SEE (editing, design, motion graphics)**
- Paste YouTube URL into Gemini 2.5 in browser
- Ask: *"Describe every visual technique, transition, tool used, and workflow step in this video"*
- Gemini actually **sees the frames** — it gives you what NotebookLM can't
- Save the Gemini output into a Google Doc → that doc goes into NotebookLM for later review
- Time: ~15 min per video

### Tier 3 — Practice Tutorials (Screen Record Yourself)
**Videos where you need to DO the thing (After Effects, Remotion, animation)**
- Watch a section → pause → do it yourself → screen record your attempt
- Your recording becomes your own tutorial reference
- Muscle memory > passive watching, especially for ADHD brains
- Time: 2-3x the video length (a 20-min tutorial = ~60 min with practice)

### The ADHD Rule: **3 → Process → 3**
- Queue exactly **3 videos** from the priority list
- Process all 3 using the appropriate tier
- Only THEN queue the next 3
- This prevents the dopamine trap of "I'll watch just one more"
