## The Hard Truth About AppleCare+ on Used Macs

> [!CAUTION]
> **AppleCare+ can only be bought within 60 days of the ORIGINAL first sale date** — not from when YOU buy the used Mac. Third-party invoices from Cashify, Amazon, etc. do NOT reset this clock.

| Scenario | Can You Buy AppleCare+? |
|---|---|
| Mac is <60 days old from original Apple/APR sale | ✅ Yes — buy via System Settings or call Apple |
| Mac is >60 days old | ❌ No — permanently ineligible |
| Previous owner bought 3-year upfront AppleCare+ | ✅ Transfers automatically with serial number |
| Previous owner has monthly AppleCare+ subscription | ❌ Non-transferable, dies when they cancel |

**AppleCare+ pricing in India:**
- 14" MacBook Pro: **₹29,900** (3-yr) or **₹999/month**
- 16" MacBook Pro: **₹40,900** (3-yr) or **₹1,379/month**

**Bottom line:** If AppleCare+ matters to you, buy **new** (sealed clearance from Unicorn or current gen from Vijay Sales). On refurbished, you're stuck with the seller's 6-month warranty.

## Buyer's Checklist (Before Paying for Any Used Mac)

Do these 5 checks **immediately** on receiving the device:

1. **MDM Lock Check**: `System Settings > Privacy & Security > Profiles` — must show NO profiles. Do a clean erase + reinstall to verify no "Remote Management" screen appears.
2. **Activation Lock**: Confirm Find My Mac is OFF and previous Apple ID is unlinked.
3. **Hardware Diagnostics**: Hold Power Button → "Loading startup options" → press `⌘+D`. Must return code `ADP000` (no issues).
4. **Battery Health**: `Apple Menu > About This Mac > System Report > Power`. Look for <250 cycles, health ≥85%. Replacement costs ₹18,000–₹24,000.
5. **Display Inspection**: Check for stuck pixels, backlight bleed, and keyboard marks on anti-reflective coating against solid black/white backgrounds.
