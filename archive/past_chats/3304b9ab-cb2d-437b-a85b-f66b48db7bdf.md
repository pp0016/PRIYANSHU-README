### 2. Step-by-Step: Formatting and Running `--process`

The `python wgp.py --process` command does not take a raw `.txt` file of prompts. Instead, it requires a structured `.json` settings file or a `.zip` queue file. The safest and most accurate way to format this list is to use WanGP's UI to generate the configuration file first, and then run it headlessly. 

**Step 1: Start the WanGP UI**
Open your terminal in the `C:\Users\renu5\Downloads\find-skill-repo\all github repos\Wan2GP` directory and start the UI normally:
```bash
python wgp.py
```

**Step 2: Build Your Queue**
1. In the Web UI, select your desired video model (e.g., Wan 2.1 or Wan 2.2).
2. Configure your base settings (resolution, steps, aspect ratio).
3. Copy **Prompt 1** into the prompt box.
4. Instead of clicking "Generate", click **"Add to Queue"**.
5. Repeat this process for **Prompt 2** and **Prompt 3**. 

**Step 3: Export the List of Prompts**
Once all three prompts are in your queue, look for the queue management buttons:
- Click **"Export Settings"** to download the queue as a JSON file (e.g., `my_settings.json`).
- *(Alternatively, you can click **"Save Queue"** to download it as a `.zip` file, which works the exact same way).*
Place this file in your Wan2GP folder. You can now close the Web UI (Ctrl+C).

**Step 4: Run Headless Generation**
Now you can generate your list of prompts in the background without loading the UI. Run the following command:
```bash
python wgp.py --process my_settings.json --output-dir ./cyberpunk_broll
```
*(If you exported a zip, run `python wgp.py --process queue.zip --output-dir ./cyberpunk_broll`)*

**Bonus Tip for Performance:**
If you want to speed up the background generation, you can add performance flags like `--profile 4` (optimized memory) or `--attention sage2` (if you have Triton installed):
```bash
python wgp.py --process my_settings.json --output-dir ./cyberpunk_broll --profile 4 --attention sdpa
```
