### 3. API Commands to Render the Video

To trigger the video render, you need to make HTTP POST requests to HeyGem's local API. Since you are on Windows, you can use PowerShell to run these commands.

**Step A: Preprocess the Audio (Model Training)**

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:18180/v1/preprocess_and_tran" -Method Post -ContentType "application/json" -Body (@{
    format = ".wav"
    reference_audio = "your_audio_filename.wav"
    lang = "en"
} | ConvertTo-Json)
```
*Note: Save the `asr_format_audio_url` and `reference_audio_text` from the response, as you'd normally need them for Text-to-Speech synthesis.*

**Step B: Submit the Video Synthesis Task**
Once you have your generated/processed audio and your silent video, submit them to the video rendering endpoint:

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8383/easy/submit" -Method Post -ContentType "application/json" -Body (@{
    audio_url = "path_to_your_audio.wav"
    video_url = "path_to_your_silent_video.mp4"
    code = "unique-task-id-1234"
    chaofen = 0
    watermark_switch = 0
    pn = 1
} | ConvertTo-Json)
```
*(Make sure to replace `path_to_your_audio.wav`, `path_to_your_silent_video.mp4`, and `code` with your actual file paths and a unique ID).*

**Step C: Check the Progress**
Video rendering takes time. You can check the status of your task using the `code` you provided in the previous step:

```powershell

```
