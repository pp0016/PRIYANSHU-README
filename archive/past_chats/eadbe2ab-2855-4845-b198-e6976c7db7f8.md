## 📐 Micro Print Page Order — Explanation

### Problem Samjho

Aapke paas ek A4 sheet hai (Portrait). Uspe **4 micro pages** aate hain:

```
┌──────────┬──────────┐
│  Top-Left │ Top-Right│
│   (TL)    │   (TR)   │
├──────────┼──────────┤
│Bottom-Left│Bottom-Right│
│   (BL)    │   (BR)   │
└──────────┴──────────┘
```

Printer **auto-duplex** hai — dono side ek sath print karke sheet nikalta hai.

### Key Physics: Paper Flip

Jab printer duplex karta hai (standard **long-edge flip** for portrait), paper **book ki tarah** palta hai — left-right mirror hota hai:

| Front Position | → Back Position |
|---|---|
| Top-Left (TL) | Top-**Right** (TR) |
| Top-Right (TR) | Top-**Left** (TL) |
| Bottom-Left (BL) | Bottom-**Right** (BR) |
| Bottom-Right (BR) | Bottom-**Left** (BL) |

### 8 Pages ka Order

Aap chahte ho ki cut karne pe:
- TL cut = **Page 1** (front) → **Page 2** (back)
- TR cut = **Page 3** (front) → **Page 4** (back)
- BL cut = **Page 5** (front) → **Page 6** (back)
- BR cut = **Page 7** (front) → **Page 8** (back)

Toh front-back positions yeh hongi:

#### ✅ FRONT Side (Sheet 1 — Page 1 of print):
```
┌──────────┬──────────┐
│  Page 1   │  Page 3  │
│   (TL)    │   (TR)   │
├──────────┼──────────┤
│  Page 5   │  Page 7  │
│   (BL)    │   (BR)   │
└──────────┴──────────┘
```

#### ✅ BACK Side (Sheet 1 — Page 2 of print) — Long Edge Flip:
```
┌──────────┬──────────┐
│  Page 4   │  Page 2  │
│   (TL)    │   (TR)   │
├──────────┼──────────┤
│  Page 8   │  Page 6  │
│   (BL)    │   (BR)   │
└──────────┴──────────┘
```

**Kyun?** Kyunki flip karne pe TL↔TR aur BL↔BR swap hota hai:
- Front TL (Page 1) ke peeche → Back TR = **Page 2** ✅
- Front TR (Page 3) ke peeche → Back TL = **Page 4** ✅
- Front BL (Page 5) ke peeche → Back BR = **Page 6** ✅
- Front BR (Page 7) ke peeche → Back BL = **Page 8** ✅

### PDF mein Page Order

Agar aapka original PDF hai: `1, 2, 3, 4, 5, 6, 7, 8`

Toh **micro-print ready PDF** mein pages is order mein rakhne padenge:

> **Front sheet page:** `1, 3, 5, 7`
> **Back sheet page:** `4, 2, 8, 6`

Ab main ek Python script banata hoon jo yeh automatically kar de — kisi bhi number of pages ke liye!
