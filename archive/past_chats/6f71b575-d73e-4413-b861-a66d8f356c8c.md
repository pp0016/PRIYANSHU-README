## ⚡ Quick Example — Animated Circle (to test setup)

```python
from manim import *

class HelloManim(Scene):
    def construct(self):
        circle = Circle(color=BLUE, fill_opacity=0.5)
        text = Text("Hello Manim!", font_size=48)
        self.play(Create(circle))
        self.play(Write(text.next_to(circle, DOWN)))
        self.wait(1)
```

**Render it with:**
```bash
manim -pql hello.py HelloManim
```
- `-p` = preview (auto-open)
- `-ql` = quality low (fast render)
- `-qh` = quality high
