**The math is easy. Getting it to match Erasio's precision is a different problem.** Here's why:

1. **The watermark template is everything.** Erasio's developers spent time extracting the *exact* pixel-perfect sparkle overlay that Google uses — its exact position, exact opacity value, exact color. 3. **Video processing is harder than images.** For images — straightforward, maybe 50 lines of Python. For videos — you need frame-by-frame extraction, processing, and re-encoding. Python can do this with OpenCV + FFmpeg, but video quality loss during re-encoding is a real concern. Erasio uses browser-native WebCodecs which handles this differently.

4. **You can't copy their code.** Chrome extensions are minified/obfuscated JavaScript. Even if you extract the extension files, the watermark template data (the actual overlay image/mask) is embedded in a way that requires reverse-engineering to extract. It's not copy-paste.
