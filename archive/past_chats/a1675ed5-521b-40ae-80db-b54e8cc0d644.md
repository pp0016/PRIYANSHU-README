### ANSWER
You cannot use VideoScribe via the terminal. It is a strictly manual, desktop-based graphical application with zero headless API, CLI, or automated batch rendering support. 

However, since you already use Remotion and FFmpeg, you can bypass VideoScribe entirely. The specific visual effect you want is called SVG path drawing, and you can build an automated, terminal-controlled version of it using Remotion's `@remotion/paths` library or specific open-source Python CLI tools.

### WHY

**The VideoScribe limitation:** 
VideoScribe is designed for non-technical users. It requires a human to click, drag, set camera positions, and manually click "Render." There is no way to send it a JSON payload or script to output a video automatically.

**How to automate this yourself (The Expert Path):**

**1. Remotion (The best option since you know it)**
The "hand holding a marker" whiteboard effect is just basic geometry and masking. Here is the exact technical workflow:
* Import an SVG file. Ensure it has `fill="none"` and defined strokes.
* Install `@remotion/paths`.
* Use `getLength()` to calculate the total length of the vector lines.
* Use `evolvePath()` with an interpolated frame count to reveal the SVG line frame-by-frame.
* To add the "hand": Use the `getPointAtLength()` function. This gives you the exact X,Y pixel coordinates of the vector line at any given frame. You attach a PNG image of a hand to those coordinates, and the hand will perfectly follow the line as it draws.

**2. Open-Source Python CLI Tools**
If you want ready-made terminal tools instead of coding it in React:
* **`whiteboard-animator`** (by masihsultani on GitHub): A CLI tool built specifically for this. It takes a static image, applies a hand-drawn reveal mask, syncs it to an audio file, and outputs an MP4 using FFmpeg. 
  * Usage: `whiteboard-animate scene.png --duration 8 -o scene.mp4`
* **`handanim`** (by subroy13 on GitHub): A Python library explicitly designed for programmatic animation of human-style sketching, targeted at educational videos. 

### COUNTER

The programmatic approach (Remotion/Python) gives you the speed and automation you want, but it introduces a massive asset problem. 

VideoScribe is successful because they pay human artists to manually define the "draw paths" inside tens of thousands of proprietary SVGs. When a human draws a house, they draw the frame, then the roof, then the windows. When you feed a random stock SVG into Remotion or a Python tool, the computer traces the raw mathematical vector coordinates. It might draw the window first, then a random line on the roof, then jump to the door. It looks chaotic, not human. 

To make automated whiteboard animation look like an expert did it, you will have to manually clean up and re-order the vector paths inside Adobe Illustrator or Inkscape for every new graphic before feeding it to your script.

### CONDITIONS

Building a CLI-driven whiteboard animation pipeline using Remotion or Python is the correct decision **ONLY IF** your channel relies on a reusable library of standard assets (charts, text generation, generic icons) that you prepare once. 

If your format requires unique, highly detailed custom illustrations for every single video, the programmatic approach will fail. The time you save on automated rendering will be completely lost debugging SVG coordinates to make the hand draw them logically. In that scenario, paying for a subscription to a UI tool like Animaker (which has an AI prompt-to-whiteboard generator) is the more realistic path for volume.
