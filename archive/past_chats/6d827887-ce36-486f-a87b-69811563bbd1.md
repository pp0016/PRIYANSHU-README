# Overnight Video Compression Skill

This skill is designed to handle massive, multi-gigabyte directories of videos. It recursively iterates through folders, compressing videos using FFmpeg to achieve up to a 70-90% file size reduction with virtually zero visual quality loss. 

## Core Execution Rules
1. **Universal Codec:** ALWAYS use the `libx264` codec. Avoid H.265 (HEVC) to prevent missing codec errors on Windows.
2. **Compression Settings:** Use `-crf 28 -preset fast -c:a aac -b:a 128k`.
3. **No-Stall Execution:** ALWAYS include the `-nostdin` flag in the FFmpeg arguments to prevent the background process from hanging or pausing unexpectedly while waiting for input.
4. **Idempotency (Resumable):** The script must check the destination folder first. If the compressed video already exists and has a file size greater than 0, it must be skipped so the script can safely resume if it is interrupted.

## The Compression Script

When the user requests overnight compression, save the following PowerShell script to a `.ps1` file (e.g., `compress.ps1`), update the `$sourceDir` and `$destDir` variables for their specific task, and run it as a background task.
