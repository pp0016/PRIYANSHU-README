3. **Bandwidth & Latency Mismatch:** Local RAM delivers 100–800 GB/s at ~90–100 ns latency. Thunderbolt 4/5 PCIe tunneling delivers only 3.2–8.0 GB/s at 500–1,000 ns (link transit) and 100–300 µs (network bridge RTT). Accessing memory across Thunderbolt imposes up to a **250× bandwidth penalty** and a **1,000× to 3,000× latency penalty**.
4. **Fundamental Hardware Limits:** The SoC Memory Controller is hardwired exclusively to on-package LPDDR PHYs with no external routing; Thunderbolt carries packetized I/O and lacks hardware cache coherency (MESI/MOESI), making native CPU load/store (`LDR`/`STR`) instructions impossible.
5. **Comparison to x86/Linux:** Multi-socket x86 servers rely on dedicated coherent pin fabrics (Intel UPI / AMD Infinity Fabric) and CXL 3.0 (`CXL.mem`), which Apple Silicon does not implement.
