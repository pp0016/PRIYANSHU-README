## Can Remotion / FFmpeg do the "Stick Figure climbing ladders" animation?

### ✅ Yes — Both can do it. Here's how they compare for THIS specific task:

| Feature | Remotion | FFmpeg |
|---------|----------|--------|
| **Character movement** | `interpolate()` moves the stick figure's Y position frame-by-frame — precise, easy to tweak | `overlay` filter with animated `y` offset — works but painful to fine-tune |
| **Multiple jumps (ladder to ladder)** | Chain `<Sequence>` blocks — each jump is its own timed animation with spring physics | Chain filter segments — clunky, no live preview |
| **Live preview** | ✅ Remotion Studio — scrub timeline, see exact frame | ❌ Must render → watch → re-render |
| **Easing / bounce** | `spring()` or `Easing.bezier()` — natural-looking jump arcs | Manual math in filter expressions |
| **Best for this test** | ✅ **Winner** — perfect for sprite animation testing | Possible but miserable to iterate |

### Verdict: **Start with Remotion.** It's literally built for this — moving images on a timeline with animation curves.
