### The Only 3 Things Python Actually Does

```
1. INPUT    →  Kuch do (image, file, text)
2. PROCESS  →  Kuch karo (cut, mix, change)  
3. OUTPUT   →  Kuch nikalo (video, new image, sound)
```

**Bas. Itna hi hai.** Every single Python project in the world — from Instagram filters to NASA rockets — is just these 3 steps.

### How the Popup Video Thing Works (Kitchen Analogy) 🍳

Imagine you're making a sandwich:

| Step | Kitchen | Python |
|:--|:--|:--|

### How Python Reads Your Instructions

```python
# English: "Open this image"
image = open("photo.png")

# English: "Find all objects in it"
objects = find_objects(image)

# English: "Make each one popup one by one"
for thing in objects:
    popup(thing)

# English: "Add pop sound"  
add_sound("pop.wav")

# English: "Save as video"
save("final_video.mp4")
```

**Yahi hai coding.** English mein sochta hai → Python mein likhta hai. Bas rules thode strict hain (spelling, brackets, etc.)
