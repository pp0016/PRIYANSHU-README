### 🤖 Antigravity
Here is exactly how web browsers handle half-downloaded files:

When you start downloading something in Chrome or Edge, the browser immediately creates a placeholder file inside your **Downloads** folder. 
* Chrome and Edge attach the `.crdownload` extension to the end of it (e.g., `movie.mp4.crdownload`).
* Firefox attaches the `.part` extension.

As the file downloads, that `.crdownload` file grows in size. When it reaches 100%, the browser simply deletes the `.crdownload` text from the file name, turning it into the real file.

**What happens if it stops halfway?**
1. **If you PAUSE it:** The `.crdownload` file stays right there in your Downloads folder forever, holding onto whatever data it managed to grab. If it got to 1 GB before you paused, that file is 1 GB of dead weight.
2. **If you officially CANCEL it:** (using the 'Cancel' button in the browser), the browser is usually smart enough to automatically delete the `.crdownload` file for you.
3. **If your internet drops or the browser crashes:** The `.crdownload` file gets stranded in your Downloads folder forever. The browser forgets about it, but the heavy file remains.
