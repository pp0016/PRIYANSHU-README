# Clipping — Overview

> Separate income stream from YouTube channels. Runs in parallel with content creation.

## What Is Clipping?
- Take other creators' long-form content → cut into short-form clips (Shorts, Reels, TikTok)
- Earn money based on views (RPM deals)
- No need to create original content — you're repurposing existing creator content with permission
