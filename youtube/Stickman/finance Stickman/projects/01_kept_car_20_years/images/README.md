# 📁 images/ — Sequential Visual Scene Assets

## 🎯 Purpose
Stores the complete sequence of still illustrations generated via Nano Banana 2 for automated FFmpeg concatenation.

## ✅ What is REQUIRED Here
1. **240 to 480 Sequential PNG Frames**:
   - Naming convention: strictly `img_001.png`, `img_002.png`, `img_003.png`, ... `img_NNN.png`.
   - Resolution: Exactly 1920x1080 (16:9).
   - Cadence: One visual cut every 2.5–3.0 seconds (average 2.75s).
2. **Visual Style DNA Compliance**:
   - Minimalist 2D black ink outline stick figures.
   - **Protagonist Expression Law**: The recurring stickman protagonist displays a completely NEUTRAL, calm, unbothered expression ALWAYS.
   - **Supporting Characters**: Carry 100% of the emotional volatility (shock, envy, boastfulness, panic).
   - **Backgrounds**: Warm, semi-realistic American environments (suburban kitchens, corporate cubicles, big-box parking lots).
   - **Restricted Color Accents**: Emerald green (`#10b981`) for portfolio/gains, crimson red (`#ef4444`) for debt/lifestyle traps.

## ❌ What is NOT REQUIRED / FORBIDDEN
- NEVER include video clips, animated MP4s, or GIFs.
- NEVER add floating headline text or captions inside the images (creates banner blindness).
- NO 3D uncanny rendering, photographic face-swapping, or dark void-black backgrounds.
